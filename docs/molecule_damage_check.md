# 分子损坏检测：为什么 1.780 Å 的分子间 N–N 键漏检

以 tnt22_1 第 13 代 2483 号结构（softmutate）为例：两个 CL-20 分子之间出现了
**1.780 Å 的 N···N 接触**（共价键长度），即两个分子被焊在一起，但 checkMolecules
三道检查全部放行。

## 现在的三道检查

| 检查 | 位置 | 判据 | 2483 的结果 |
|---|---|---|---|
| Z 矩阵分解 | readMOL.py:145-151（maxdist=0.6） | 分子内键长偏离模板 > 0.6 Å | 通过（CL-20 最大偏离 0.42 Å） |
| 分子间/分子内镜像距离 | newMolCheck.py:70、newMolCheck.py:83-96 | 任意原子对距离 ≤ minDistMatrice 阈值 | **通过**：N–N 阈值 1.77，实测 1.780 |
| 分子内成键数增加 | mol_bond_table.py:38 + readMOL.py:167-171 | cur_bonds - ref_set 非空 | 通过：分子内键集合与模板完全一致 |

也就是说：**分子内部完全正常**（键集合与模板逐一吻合，叠合 RMSD 0.65 Å，与同代被接受的
结构 0.5–0.8 Å 同一水平），损坏发生在**分子之间**。而分子之间只有 minDistMatrice 这一道门。

## 漏检的直接原因：两套判据不一致

同一个原子对，代码里有两个「是否成键」的尺度：

- 分子内（键图）：d < rcov_i + rcov_j + BOND_TOL，BOND_TOL = 0.45（mol_bond_table.py:19）。
  N–N：0.71 + 0.71 + 0.45 = **1.87 Å**。
- 分子间（距离门）：minDistMatrice（newMolCheck.py:70，来自 INPUT/MATLAB）。N–N：**1.77 Å**。

重原子对上，距离门系统性地比成键判据**小 0.05–0.12 Å**（N–N 1.77/1.87、N–O 1.75/1.82、
C–O 1.75/1.87、C–C 1.94/1.97），于是落在 1.78–1.95 Å 这段窗口里的**真实化学键**既不会被
距离门判为过近，也不会被键图检查看到（后者只看分子内部）。这就是 1.780 漏掉的全部原因——
差 0.01 Å。

## 建议（按性价比排序）

1. **加一道跨分子成键检查**（直接对症）。把分子内那套成键判据也用在**分子之间**的原子对上
   （含周期镜像，±1 个晶胞即可）：任意跨分子原子对满足 d < rcov_i + rcov_j + BOND_TOL 即判
   损坏。等价于把判据统一成 flag if d ≤ max(minDistMatrice, rcov_i+rcov_j+BOND_TOL)，
   两套尺度取并集，1.780 就会被 1.87 抓住。H 相关对的成键判据比距离门小（H–H 1.07/1.73），
   取并集不会误伤正常的氢键/接触。
2. **给距离门加「近似命中」告警**。1.780 对 1.77 只差 0.01 Å，硬阈值天然会在边界上摇摆。
   建议 d ≤ thr + margin（margin ≈ 0.15–0.2 Å）时**只告警不判死**，把这类擦边结构打进
   OUTPUT.txt，人工就能看见。
3. **用连通性聚类代替固定分块**（治本）。现在分子是按 MtypeLIST 的元素计数**硬分块**的
   （readMOL.py:48-66），所以「同类型分子之间换原子」、分子融合、断下来的碎片，在分块视角
   下都是隐形的。改成对整个晶胞（含周期镜像）按成键判据做并查聚类，再校验每个连通块的
   元素组成是否正好等于某个模板（21 / 36 个原子、C/H/N/O 计数吻合）：融合会体现为块大小
   42/72，原子交换会体现为组成不对，脱落的基团会体现为多出一个碎片块。顺带补上另一个盲区：
   现在的键图检查只看 cur - ref（**多出来**的键），ref - cur（**丢掉**的键）完全不看——
   一个掉下来的 H（悬空、不再与任何原子成键）不会多出键，因此永不触发。
4. **把 Z 矩阵检查从「只看键长」扩展到角度/二面角或叠合 RMSD**。目前只比较第 0 列键长、
   容忍 0.6 Å（readMOL.py:147）；笼形分子开笼、基团翻转这类「键长都对、形状错了」的损坏
   抓不到。加 Kabsch 叠合后的 RMSD（对 CL-20/TNT 实测正常结构 0.5–0.8 Å，可取 1.0 Å 为界）
   或直接比较 Z 矩阵的角度列，代价都不大。

## 复现/自查用的量

对 2483（按 results1/Individuals.traj 的原子编号，C 1–26 / O 27–62 / N 63–92 / H 93–114，
按类型分组）：

- 分子顺序 [TNT, TNT, CL20, CL20]，需按 STDMOL[*].types 从类型分组坐标还原，并用 Movecoor
  解开跨周期边界的分子后再量距离。
- 最近跨分子接触：N(79)–N(86) 1.779 Å、N(74)–N(91) 1.780 Å（mol3–mol4，即两个 CL-20）；
  其余最近接触 2.19 Å 起（正常）。同代被接受的结构（2461 / 2463）最近接触为 2.07–2.22 Å。
- 每分子 Z 矩阵键长最大偏离 0.015（TNT）/ 0.422（CL-20）Å，键集合与模板零差异。

顺带一提：2483 在 Individuals 里的 fitness 是 100000（被踢掉），但**不是分子检测写的**——
它的焓值列仍是 -1143.967，说明 Enthalpies[-1] 从未被置 100000，是别的大门（疑似
degradeSimilar 的相似结构惩罚，gpevo/FunctionFolder/sys/degradeSimilar.py:44）挡下的。
也就是说这类损坏结构目前是靠「长得太像」偶然被挡，而不是被认出来。
